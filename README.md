# Python-arithmetic_Calculator
A simple command-line calculator in Python that performs addition, subtraction, multiplication, division, and modulus, with division-by-zero handling.

A command-line calculator built in Python. The user enters two numbers, chooses an operation from a menu, and the program prints the result.

## Features

- Addition, subtraction, multiplication, division, and modulus
- Works with whole numbers and decimals (uses `float`)
- Handles division by zero and modulus by zero with a clear error message
- Handles invalid menu choices

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository:
   ```
   git clone https://github.com/<Hamna-97>/Python-arithmetic-Calculator.git
   ```
3. Run the program:
   ```
   python_arithmetic_operations_calcultorpy.py
   ```

## Example

```
----Welcome to Python Arithmetic Calculator----
Enter first number: 10
Enter second number: 4
Select operation:
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Modulus
Enter choice (1/2/3/4/5): 4
You selected option 4.
The result of division is: 2.5
```

## Concepts Practiced

- Taking user input with `input()`
- Type conversion with `float()`
- Arithmetic operators (`+`, `-`, `*`, `/`, `%`)
- Conditional statements (`if`, `elif`, `else`) and nested `if`
- f-strings for formatted output

## Known Limitations

- The program runs one calculation and then exits.
- Entering text instead of a number will cause an error.
